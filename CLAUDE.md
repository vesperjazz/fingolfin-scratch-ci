# A scratch repo for Fingolfin's smoke tests

Built by a script of the Fingolfin repo. A session here is one of a smoke test: it builds the ticket it was given, and nothing else.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues, read with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five triage labels, by their default names. See `docs/agents/triage-labels.md`.
